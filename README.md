# 🗳️ 스마트 QR 선거인명부 (Q-Vote)
> **팀명:** 오인용오조
> **한 줄 소개:** 단방향 암호화(SHA-256) 기술과 QR 코드를 활용해 개인정보 유출을 막고 투표소 대기 시간을 획기적으로 줄이는 오프라인 투표소 전용 스마트 유권자 인증 시스템

## 1. 해결하고자 하는 사회 문제
* **투표소 병목 현상:** 선거일마다 반복되는 신분증 대조 및 수기 명부 확인으로 인한 긴 대기 시간
* **개인정보 노출 우려:** 수많은 사람이 열람하는 종이 선거인명부의 특성상 민감한 개인정보(주민등록번호 등) 유출 위험 존재

## 2. 프로젝트 핵심 솔루션
* **개인정보 원천 차단:** 유권자의 민감한 정보를 DB에 평문으로 저장하지 않고, 클라이언트 단에서 즉시 SHA-256 해시값으로 변환하여 통신 및 저장합니다.
* **비밀투표 원칙 준수:** 100% 온라인 투표의 한계(대리 투표 등)를 극복하기 위해 '신원 인증'만 디지털화(QR)하고 실제 기표는 오프라인 종이로 진행합니다.
* **이중 투표 완벽 차단:** 인증 완료 즉시 해당 유권자의 투표 상태(`is_voted`)를 업데이트하고 발급된 1회용 토큰을 영구 폐기하여 재사용을 막습니다.

## 3. 시스템 아키텍처 및 실행 흐름 (O2O 하이브리드)
프론트엔드와 백엔드를 Spring Boot 단일 프로젝트(`src/main/resources/static`)로 통합하여 빠르고 안정적인 서비스를 제공합니다.

* 📱 **유권자 (스마트폰):** 
  * `ngrok` 배포 링크를 통해 외부망에서 시스템에 접속(`index.html`)합니다.
  * 본인 정보를 입력하면 즉시 1회용 투표 QR 코드가 발급됩니다.
* 💻 **투표소 관리자 (노트북/웹캠):** 
  * 보안 및 카메라 권한 확보를 위해 투표소 기기(로컬망)에서 직접 접속(`http://localhost:8080/certificate.html`)합니다.
  * 유권자의 스마트폰 QR을 스캔하여 즉시 유효성을 검증하고 해당 선거구를 화면에 출력합니다.

## 4. 활용 기술
* **Backend:** Java, Spring Boot, Spring Data JPA
* **Database:** MySQL (테스트용 서울/인천 선거구 해시 더미 데이터 30건 구축 완료)
* **Frontend:** HTML5, CSS, Vanilla JS (qrcode.js, html5-qrcode)
* **Security:** SHA-256 (단방향 해시 암호화)
